# General Instructions

- Use PHP and the newest version of Symfony
- Follow PSR-12 coding style guidelines
- Project-specific classes must be declare strict_types
- Method should be properly documented
- Method parameters and return types should be type hinted
- Never use .env for anything except default/example values. All local environment settings should go in a local .env file. Never submit local .env files to git.
- Use git for code versioning
- All changes should be small and atomic. Use feature branches for each new feature.
- Branches can only be merged to the develop branch via a Github PR.
- No code changes allowed directly on the develop branch.
- Always ask before adding new dependencies
